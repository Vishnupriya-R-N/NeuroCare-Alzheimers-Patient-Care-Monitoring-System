# NeuroCare – Alzheimer’s Patient Care & Monitoring System

NeuroCare is a web-based healthcare management system designed to support the care and monitoring of Alzheimer's patients.

## Features

* User registration and login
* JWT authentication
* Role-based access
* Patient routine management
* Medication reminders
* Appointment management
* Caregiver monitoring
* Doctor health records
* Emergency alerts
* Admin management
* Real-time communication using Socket.IO

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* Socket.IO

## Modules

* Authentication
* Patient
* Caregiver
* Doctor
* Admin
